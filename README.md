# Сервис управления рассылками (Mailing Service)

Веб-приложение на Django, предназначенное для управления рассылками сообщений клиентам. Пользователи могут создавать базы получателей, шаблоны писем, а также настраивать автоматическую или ручную отправку сообщений.

## Функционал

- **Управление пользователями**: Кастомная модель пользователя (`User`), где авторизация происходит по Email (вместо стандартного `username`).
- **Управление получателями**: Полный CRUD (создание, чтение, обновление, удаление) для клиентов (Ф.И.О., Email, комментарий). У каждого пользователя своя база клиентов.
- **Управление сообщениями**: Полный CRUD для шаблонов писем (тема, тело письма).
- **Управление рассылками**: Полный CRUD для рассылок. Настройка временного окна (начало и конец отправки), выбор сообщения и списка получателей.
- **Динамический статус**: Рассылка автоматически меняет статус («Создана», «Запущена», «Завершена») в зависимости от текущего времени и заданного окна.
- **Валидация данных**: Запрет на указание даты начала в прошлом и проверка, что начало раньше окончания.
- **Отправка писем**: 
  - Запуск вручную через веб-интерфейс.
  - Запуск через кастомную команду в терминале: `python manage.py send_mailing <ID>`.
  - Логирование каждой попытки отправки (успешно/неуспешно, ответ сервера) через `bulk_create` (batch-вставка).
- **Статистика на главной**: Отображение общего количества рассылок, количества активных рассылок и общего числа получателей.
- **Кеширование**: Настроен Redis для кеширования статистики на главной странице.
- **Аутентификация**: Регистрация, вход, выход и восстановление пароля (через стандартные механизмы Django).

## Стек технологий

- **Python 3.10+**
- **Django 5/6**
- **SQLite** (база данных по умолчанию)
- **Redis** (для кеширования)
- **Bootstrap 5** (для стилизации интерфейса)
- **django-redis** (интеграция Redis)
- **Pillow, python-dotenv**

## Установка и запуск

### 1. Клонирование репозитория и настройка окружения

- git clone <ссылка-на-ваш-репозиторий>
- cd mailing_service
- python -m venv .venv

Активация виртуального окружения:
- Windows: .venv\Scripts\activate
- macOS/Linux: source .venv/bin/activate

### 2. Установка зависимостей

pip install -r requirements.txt

### 3. Настройка переменных окружения
Создайте файл .env в корне проекта (на основе .env.example) и укажите необходимые настройки:

- env

SECRET_KEY=ваш_секретный_ключ
DEBUG=True
REDIS_URL=redis://127.0.0.1:6379/1
EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
DEFAULT_FROM_EMAIL=noreply@mailing.local

### 4. Запуск Redis
Для работы кеширования (статистика на главной) необходим Redis. Запустите его через Docker:


docker run -d --name mailing-redis -p 6379:6379 redis:7-alpine

(Если Docker не установлен, можно использовать Memurai для Windows или отключить кеш в настройках, заменив бэкенд на LocMemCache).

### 5. Миграции и создание суперпользователя

- python manage.py makemigrations
- python manage.py migrate
- python manage.py createsuperuser

- При создании суперпользователя потребуется ввести только Email и пароль.

### 6. Запуск сервера

python manage.py runserver

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## Использование

Перейдите на главную страницу и авторизуйтесь (или зарегистрируйте нового пользователя).

В меню навигации доступны разделы: Получатели, Сообщения, Рассылки.

Создайте получателей и шаблон сообщения.

Создайте рассылку, указав время начала и окончания. Убедитесь, что текущее время входит в этот интервал.

Запустите рассылку:

Нажмите кнопку «Запустить рассылку сейчас» на странице рассылки.

Или через терминал: python manage.py send_mailing 1 (где 1 — ID рассылки).

Проверьте результат в консоли (так как используется консольный бэкенд почты) и в таблице попыток на странице рассылки.
