# Сервис управления рассылками (Mailing Service)

Веб-приложение на Django, представляющее собой полноценный сервис для управления email-рассылками. Проект включает в себя создание базы клиентов, шаблонов писем, настройку рассылок и отслеживание статистики отправки.

Проект разработан в рамках курсовой работы и состоит из двух частей: базовый функционал (CRUD, отправка) и расширенный (аутентификация, роли, кеширование).

## 🚀 Основной функционал

### Часть 1. Разработка сервиса
- **Управление клиентами**: Полный CRUD для базы получателей (Email, Ф.И.О., комментарий).
- **Управление сообщениями**: Полный CRUD для шаблонов писем (тема, тело).
- **Управление рассылками**: CRUD для рассылок с настройкой временного окна (дата начала и окончания).
- **Динамический статус**: Статус рассылки («Создана», «Запущена», «Завершена») рассчитывается на лету на основе текущего времени.
- **Валидация**: Запрет на установку даты начала в прошлом и проверка, что начало раньше окончания.
- **Отправка по требованию**: 
  - Вручную через веб-интерфейс.
  - Через консольную команду: `python manage.py send_mailing <ID>`.
- **История попыток**: При отправке создаются записи `Attempt` (успешно/неуспешно) через `bulk_create` (batch-вставка).
- **Статистика на главной**: Отображение общего числа рассылок, активных рассылок и количества получателей.

### Часть 2. Расширение функциональности (ДОБАВЛЕНО)
- **Аутентификация**: Регистрация, вход, выход и восстановление пароля.
- **Подтверждение Email**: При регистрации отправляется письмо со ссылкой активации (токен). Доступ к сервису возможен только после подтверждения почты.
- **Роли (Пользователь / Менеджер)**:
  - *Пользователь*: Видит и управляет только своими клиентами и рассылками.
  - *Менеджер*: Видит данные всех пользователей, может блокировать аккаунты и отключать чужие рассылки.
- **Страница статистики**: Отдельный дашборд с подсчетом успешных/неуспешных попыток и количества отправленных писем.
- **Кеширование**: 
  - Серверное (Redis) для главной страницы и статистики.
  - Клиентское (браузерное) для оптимизации загрузки.

- **Python 3.10+**

## Установка и запуск

### 1. Клонирование репозитория и настройка окружения

- git clone <ссылка-на-ваш-репозиторий>
- cd mailing_service
- python -m venv .venv

Активация виртуального окружения:
- Windows: .venv\Scripts\activate
- macOS/Linux: source .venv/bin/activate

### 2. Установка зависимостей

pip install -r requirements.txt

### 3. Настройка переменных окружения
Создайте файл .env в корне проекта (на основе .env.example) и укажите необходимые настройки:

- env

SECRET_KEY=ваш_секретный_ключ
DEBUG=True
REDIS_URL=redis://127.0.0.1:6379/1
EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
DEFAULT_FROM_EMAIL=noreply@mailing.local

### 4. Запуск Redis
Для работы кеширования (статистика на главной) необходим Redis. Запустите его через Docker:


docker run -d --name mailing-redis -p 6379:6379 redis:7-alpine

(Если Docker не установлен, можно использовать Memurai для Windows или отключить кеш в настройках, заменив бэкенд на LocMemCache).

### 5. Миграции и создание суперпользователя

- python manage.py makemigrations
- python manage.py migrate
- python manage.py createsuperuser

- При создании суперпользователя потребуется ввести только Email и пароль.

### 6. Запуск сервера

python manage.py runserver

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## Инструкция по использованию
### Роли и доступ
По умолчанию все новые пользователи имеют роль «Пользователь». Чтобы сделать пользователя «Менеджером»:

- Зайдите в админку (/admin/) под суперпользователем.

- Откройте нужного пользователя.

- Поставьте галочку «Менеджер» (is_manager) и сохраните.

### Сценарий работы
Регистрация: Зарегистрируйтесь на сайте. Скопируйте ссылку активации из консоли (т.к. используется консольный бэкенд email) и перейдите по ней.

Создание данных: Добавьте получателей (клиентов) и сообщения (шаблоны писем).

Создание рассылки: Укажите даты начала и окончания (текущее время должно попадать в этот интервал), выберите сообщение и получателей.

Отправка: Нажмите кнопку «Запустить рассылку» на странице рассылки или используйте команду в терминале:

`python manage.py send_mailing 1`

Статистика: Перейдите в раздел «Статистика», чтобы увидеть результаты отправки.

### Тестирование
В проекте написаны unit-тесты для проверки моделей, валидации форм, сервиса отправки (с моками) и разграничения прав доступа.

Запуск тестов:

`python manage.py test`
